# Рейтинг и формулы расчёта

## 1. Расчёт калорий в отчёте

### Формула строки отчёта

```
line_calories = weight_grams × product.calories_per_100g / 100
```

**Пример:**
- Яйца: 100 г × 157 ккал/100г / 100 = **157 ккал**
- Помидор: 20 г × 20 ккал/100г / 100 = **4 ккал**
- Лук: 20 г × 41 ккал/100г / 100 = **8.2 ккал**
- Масло подсолнечное: 5 г × 899 ккал/100г / 100 = **44.95 ккал**

**Итого за день:** 157 + 4 + 8.2 + 44.95 = **214.15 ккал**

### Автоматический пересчёт
- При добавлении/изменении/удалении строки отчёта — пересчёт `line_calories` и `total_calories`.
- При сохранении отчёта — фиксация `total_calories`.
- При редактировании отчёта — полный пересчёт всех строк.

## 2. Рейтинг MVP: Дисциплина

### Формула

```
discipline_percent = (filled_days / template.duration_days) × 100
```

**Где:**
- `filled_days` — количество дней, для которых существует запись в `DailyReport` (не пустая, имеет хотя бы одну строку)
- `template.duration_days` — общая длительность марафона

### Ранжирование (место)

```
Сортировка по убыванию discipline_percent:
    1. discipline_percent DESC
    2. filled_days DESC (при равенстве процента)
    3. enrolled_at ASC (при равенстве дней — кто раньше записался, тот выше)
```

**Пример:**

| Участник | Заполнено дней | Всего дней | Дисциплина | Место |
|----------|---------------|------------|------------|-------|
| Анна | 14 | 14 | 100% | 1 |
| Борис | 12 | 14 | 85.7% | 2 |
| Вера | 10 | 14 | 71.4% | 3 |
| Глеб | 10 | 14 | 71.4% | 4 (записался позже Веры) |

### Обновление рейтинга

- **Периодичность:** раз в сутки (cron-задача, например в 00:05 по UTC)
- **Алгоритм:**
    1. Выбрать все потоки со статусом `running` или `finished`
    2. Для каждого потока:
        3. Получить все записи (StreamEnrollment)
        4. Для каждой записи посчитать `filled_days` (COUNT DISTINCT day_number в DailyReport)
        5. Рассчитать `discipline_percent`
        6. Отсортировать, назначить `rank`
        7. Сохранить/обновить `StreamRating`

## 3. Результаты после финиша

### Сводка участника

| Показатель | Формула |
|------------|---------|
| Дисциплина | `filled_days / duration_days × 100` |
| Место | Из `StreamRating.rank` |
| Средние калории по дням | `AVG(total_calories) по всем заполненным дням` |
| Средние калории по потоку | `AVG(total_calories) по всем участникам и всем их дням` |

### График калорий

- **Ось X:** дни марафона (1..N)
- **Ось Y:** калории (ккал)
- **Линия 1:** калории участника по дням (0 для незаполненных)
- **Линия 2:** средние калории по потоку по дням

**Формула точки графика:**
```
day_value = COALESCE(DailyReport.total_calories, 0)
stream_avg = AVG(DailyReport.total_calories) GROUP BY day_number
```

## 4. Будущие формулы (не MVP)

| Формула | Когда | Описание |
|---------|-------|----------|
| Рейтинг по калорийному дефициту | Версия 2 | Для марафонов на похудение: чем ближе к целевому дефициту — тем выше |
| Рейтинг по качеству рациона | Версия 2 | Учёт БЖУ (белки/жиры/углеводы) при наличии в базе продуктов |
| Рейтинг по оценкам ментора | Версия 2 | Ментор оценивает отчёты, рейтинг по средней оценке |
| Командный рейтинг | Версия 2 | Группировка участников, командное соревнование |

---

## 5. Граничные случаи

| Ситуация | Решение |
|----------|---------|
| Участник не заполнил ни одного дня | discipline_percent = 0, rank = последнее |
| Участник заполнил день, но удалил все строки | Считается незаполненным (filled_days не увеличивается) |
| Два участника с идентичными показателями | Разделение по enrolled_at (раньше записался — выше) |
| Поток только запустился (1 день) | Рейтинг считается по 1 дню, обновляется ежедневно |
| Поток завершён | Рейтинг фиксируется, больше не пересчитывается (или пересчитывается, но rank не меняется) |
