# Продуктовое видение: Платформа марафонов по здоровому питанию

## Идея
Площадка для проведения марафонов по здоровому питанию. Менторы создают образовательные программы, участники проходят их, отслеживая свой рацион и соревнуясь в дисциплине.

## Цели MVP
- Проверить спрос на формат марафонов через веб-платформу
- Дать менторам инструмент для запуска без технических навыков
- Создать соревновательный механизм (рейтинг) для удержания участников
- Получить обратную связь для следующих итераций

## Принцип первой версии
**Максимальная простота. Ни одной лишней функции.**

Каждая фича должна отвечать на вопрос: «Без этого марафон не запустится?» Если ответ «нет» — в MVP не входит.

## Что входит в MVP

### Роли
- **Ментор** — создаёт марафон-шаблон, запускает потоки, видит результаты участников
- **Участник** — записывается на поток, изучает материалы, заполняет отчёты по питанию, видит рейтинг
- **Админ** — модерирует марафоны перед публикацией (зашит в системе)

### Сущности
- Марафон-шаблон (образец без дат)
- Поток (конкретный запуск с датой начала)
- День марафона (материалы + требование отчёта)
- Отчёт участника (таблица продуктов с весом)
- Рейтинг потока (обновляется раз в сутки)
- Глобальная база продуктов с калорийностью

### Функциональность
- Регистрация с выбором роли (ментор/участник)
- Создание марафона-шаблона ментором (дни, материалы)
- Модерация админом (одобрение перед публикацией)
- Запуск потока из одобренного шаблона
- Запись участников на поток до старта
- Доступ к материалам дня по мере прохождения
- Заполнение отчёта за день (продукты из базы + вес)
- Автоматический расчёт калорий
- Рейтинг участников потока (по дисциплине — процент заполненных дней)
- Страница результатов после финиша

## Что вычеркнуто из MVP

| Фича | Почему вычеркнуто | Когда вернёмся |
|------|-------------------|----------------|
| Платежи и монетизация | Первые марафоны бесплатные для проверки спроса | Когда подтвердится конверсия |
| Лимит участников на поток | Не критично для запуска | Когда появится нагрузка |
| Чаты и комментарии | Усложняет модерацию и интерфейс | Когда участники попросят |
| Push-уведомления | Email достаточно, но и его нет в MVP | Версия 2 |
| Мобильное приложение | Веб-адаптив покрывает 80% | При масштабе |
| Редактирование запущенного потока | Принцип «запустил — идёт» | Возможно, никогда |
| Добавление продуктов участником | База заполняется админом | Когда база будет неполной |
| Несколько формул рейтинга | Одна простая формула для старта | Когда появятся разные типы марафонов |
| Аналитика для ментора | Только список участников и результаты | Когда менторы попросят статистику |
| Отклонение марафона админом | Только одобрение; коммуникация по почте | Когда поток марафонов вырастет |
| Повторное использование шаблона другим ментором | Опционально, не критично | Версия 2 |

## Ключевые метрики для проверки гипотезы
- Конверсия «посетитель → запись на поток»
- Доля заполненных дней (дисциплина участников)
- Довершение марафона (дошли до финиша / записались)
- Количество марафонов, созданных менторами
- Время от создания шаблона до одобрения
