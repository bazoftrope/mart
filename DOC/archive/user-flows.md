# Пользовательские потоки (User Flows)

## Роль: Участник (Participant)

### Поток 1: Регистрация и запись на марафон

```
Главная страница
    ↓
Кнопка «Регистрация»
    ↓
Форма регистрации:
    - Email
    - Пароль
    - Подтверждение пароля
    - Имя
    - Роль: «Участник» (выбор из двух)
    - Часовой пояс (выпадающий список IANA)
    ↓
Автоматический вход
    ↓
Главная страница (авторизованный участник)
    ↓
Список потоков (только open — набор открыт)
    - Фильтр: по дате начала, по ментору
    - Карточка: название марафона, ментор, дата начала, количество участников
    ↓
Карточка потока:
    - Описание марафона
    - Дата начала, длительность
    - Ментор
    - Список участников (количество)
    - Кнопка «Записаться» (если не записан и дата начала не прошла)
    ↓
Подтверждение записи
    ↓
Страница «Мои марафоны»
```

**Ограничения:**
- Запись возможна только до `start_date` потока.
- После записи — поток появляется в «Мои марафоны».

---

### Поток 2: Прохождение марафона (ежедневный цикл)

```
Страница «Мои марафоны»
    ↓
Выбор активного потока (status = running)
    ↓
Календарь дней марафона:
    - Дни 1..N (текущий) — доступны, кликабельны
    - Дни N+1..конец — заблокированы (серые)
    - Заполненные дни — отметка (галочка)
    ↓
Клик по дню (1..N)
    ↓
Страница дня:
    - Номер дня, название марафона
    - Материалы (если есть):
        - Текст (развёрнутый блок)
        - Аудио (плеер, если audio_url)
        - Видео (плеер, если video_url)
    - Форма отчёта:
        - Таблица: [Продукт] [Вес, г] [Калории] [Удалить]
        - Поле поиска продукта (первые буквы → выпадающий список)
        - Кнопка «Добавить продукт»
        - Итого калории за день
        - Кнопка «Сохранить отчёт»
    ↓
Сохранение → обновление калорий, галочка на календаре
    ↓
Возврат к календарю / рейтинг
```

**Ограничения:**
- День открывается по таймзоне участника.
- Отчёт можно редактировать неограниченно.
- Продукты только из глобальной базы. Если нет — нельзя добавить (MVP).

---

### Поток 3: Просмотр рейтинга

```
Страница потока (активный или завершённый)
    ↓
Вкладка «Рейтинг»
    ↓
Таблица участников потока:
    - Место
    - Имя участника
    - Заполненные дни / всего дней
    - Процент дисциплины
    - Сортировка: по месту (убывание)
    ↓
Своя строка выделена
```

**Ограничения:**
- Рейтинг обновляется раз в сутки (не real-time).
- Виден только рейтинг текущего потока.
- Во время марафона — промежуточный рейтинг.
- После финиша — финальный рейтинг.

---

### Поток 4: Просмотр результатов после финиша

```
Страница «Мои марафоны»
    ↓
Выбор завершённого потока (status = finished)
    ↓
Страница результатов:
    - Название марафона, даты
    - Сводка:
        - Заполненные дни / всего дней
        - Процент дисциплины
        - Место в рейтинге
    - График калорий по дням (линейный)
    - Средние показатели по потоку (для сравнения)
    - Ссылка на рейтинг (полная таблица)
```

## Роль: Ментор (Mentor)

### Поток 5: Создание марафона-шаблона

```
Вход / Регистрация с ролью «Ментор»
    ↓
Личный кабинет ментора
    ↓
Кнопка «Создать марафон»
    ↓
Форма шаблона (шаг 1):
    - Название
    - Описание
    - Длительность (дней, 1-90)
    ↓
Предстартовая страница (шаг 2):
    - Текст в визуальном редакторе (опционально)
    - Аудио / видео / PDF (опционально)
    ↓
Создание дней (шаг 3):
    - Для каждого дня (1..N):
        - Текст в визуальном редакторе (опционально)
        - PDF-документы (опционально, показываются под текстом)
        - Аудио (опционально)
        - Видео (опционально)
        - День может быть полностью пустым
    ↓
Сохранение черновика
    ↓
Кнопка «Отправить на проверку»
    ↓
Статус: pending_review
    ↓
Ожидание одобрения админа
```

**Ограничения:**
- В MVP нельзя редактировать после одобрения.
- Пока на проверке — можно редактировать по комментариям админа (почта вне системы).
- После одобрения — шаблон доступен для запуска потоков.

---

### Поток 6: Запуск потока

```
Личный кабинет ментора → «Мои шаблоны»
    ↓
Выбор одобренного шаблона (status = approved)
    ↓
Кнопка «Запустить поток»
    ↓
Форма:
    - Дата начала (календарь, не раньше сегодня)
    ↓
Подтверждение
    ↓
Поток создан (status = open)
    ↓
Поток появляется в публичном списке
```

**Ограничения:**
- Только из одобренных шаблонов.
- Дата начала не раньше текущей даты.
- В MVP нет лимита участников.
- Один шаблон — много потоков (разные даты).

---

### Поток 7: Мониторинг потока

```
Личный кабинет ментора → «Мои потоки»
    ↓
Список потоков:
    - Название марафона
    - Дата начала, статус
    - Количество участников
    ↓
Выбор потока
    ↓
Страница потока:
    - Список участников (имена)
    - Для завершённого: результаты каждого участника
        - Процент дисциплины
        - Место
        - Средние калории
    - Ссылка на рейтинг (таблица)
```

## Роль: Админ (Admin)

### Поток 8: Модерация марафона

```
Вход (отдельный URL / зашитые креды)
    ↓
Админ-панель
    ↓
Раздел «Марафоны на проверке»
    ↓
Список шаблонов (status = pending_review):
    - Название, ментор, дата отправки
    ↓
Просмотр шаблона:
    - Все дни, материалы
    - Длительность, описание
    ↓
Кнопка «Одобрить»
    ↓
Статус → approved
    ↓
Ментор получает возможность запускать потоки
```

**Ограничения:**
- Нет кнопки «Отклонить» в MVP.
- Если нужны правки — админ пишет ментору по почте (вне системы).
- Ментор снимает с проверки, правит, снова отправляет.

## Общие потоки

### Вход / Выход

```
Главная страница
    ↓
Кнопка «Вход»
    ↓
Форма: Email + Пароль
    ↓
Перенаправление по роли:
    - Участник → «Мои марафоны»
    - Ментор → Личный кабинет
    - Админ → Админ-панель
    ↓
Кнопка «Выход» — в любой момент
```

### Просмотр потоков (неавторизованный)

```
Главная страница
    ↓
Список потоков (open) — публично
    ↓
Карточка потока — публично
    ↓
Кнопка «Записаться» требует авторизации
```
