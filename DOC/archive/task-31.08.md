# Техническое задание: Расчет суточной калорийности и дневник питания

## 1. Вводные параметры пользователя
Для расчета персональной «Дневной нормы калорий» от пользователя требуются следующие данные:
- **Пол** (Мужской / Женский)
- **Рост** (см)
- **Вес** (кг)
- **Возраст** (годы)

---

## 2. Расчет базовой «Дневной нормы калорий»
Расчет производится по формулам (с учетом коэффициента активности 1.2).

**Для женского пола:**
`База = (6.25 * Рост + 10 * Вес - 5 * Возраст - 161) * 1.2`

**Для мужского пола:**
`База = (6.25 * Рост + 10 * Вес - 5 * Возраст + 5) * 1.2`

*Результат вычислений сохраняется как переменная `Базовая дневная норма`.*

---

## 3. Выбор цели и корректировка калорий
После расчета `Базовой дневной нормы` пользователь выбирает одну из трех целей. На основе выбора формируется **Итоговая цифра** (целевая калорийность на день).

| Цель пользователя | Формула расчета Итоговой цифры |
| :--- | :--- |
| **Сброс веса** | `Итог = База - (База * 0.15)` *(дефицит 15%)* |
| **Поддержание веса** | `Итог = База` *(без изменений)* |
| **Набор веса** | `Итог = База + (База * 0.15)` *(профицит 15%)* |

*Полученная `Итоговая цифра` является целевым ориентиром для Дневника питания.*

---

## 4. Логика отображения в Дневнике питания
Система сравнивает фактически потребленные калории за день с `Итоговой цифрой` и визуализирует результат:

- 🔴 **Превышение лимита:** 
  - *Условие:* Фактические калории > `Итоговая цифра`
  - *Визуал:* Красный крестик / Красная ячейка.
- 🟢 **Норма / Дефицит:** 
  - *Условие:* Фактические калории <= `Итоговая цифра` (человек укладывается в лимит или равен ему)
  - *Визуал:* Зелёная галочка / Зелёная ячейка.

---

## 5. Примечания для разработки
1. **Единицы измерения:** На фронтенде должны быть строгие ограничения и плейсхолдеры (Рост — см, Вес — кг, Возраст — полные годы).
2. **Коэффициент 1.2:** В формулах жестко зашит коэффициент 1.2 (низкая активность / сидячий образ жизни).
3. **Округление:** Итоговые значения калорий необходимо округлять до целых чисел (например, `Math.round()`), так как дробные калории в дневнике не имеют смысла.
